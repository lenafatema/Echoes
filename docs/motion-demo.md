# Two-minute ECHOES motion demo

## Start

Run `npm run dev`, then open the local URL printed by Vite. If port 5173 is occupied, run `npm run dev -- --host 127.0.0.1 --port 5210 --strictPort` and open `http://127.0.0.1:5210/`.

Use a WebGL-capable desktop browser, turn reduced motion off, and keep the normal world mode selected. The available in-app browser used for implementation verification could not initialize WebGL; in that environment the same run is playable with SVG fallback, but camera and physical 3D motion need a WebGL-capable browser.

Recommended real-engine route: **College tech fest → Reduce the event scale → Secure a replacement sponsor → Charge participants**. These are the current scenario choices. Finish the first path, then use **Try the other path** to reveal the actual deterministic alternative and compare the saved results.

| Time | Demonstration |
|---|---|
| 0:00–0:20 | Show all six selectable worlds. Hover or keyboard-focus a scenario, lift the miniature, rotate the bounded picker arc by drag or wheel, and select College tech fest. |
| 0:20–0:40 | Follow the stage as it moves into the focused composition. Begin and let the segmented paper cover move aside. |
| 0:40–1:00 | Choose Reduce the event scale. Show the selected row's ink response and the stage updating from the actual decision, including its follow-on supplier-risk condition. |
| 1:00–1:25 | Show the four role groups separate. Follow the actual Budget, Days, Morale, and Readiness values and cause copy. Click or press Space to finish the reveal early, then continue. |
| 1:25–1:42 | Complete the replacement-sponsor and participant-fee decisions. At the engine's terminal state, let the recorded progress-history line and its history markers appear. |
| 1:42–2:00 | Use Try the other path to switch to or create Path B, then compare the two stored results. Show the actual verdict and difference rows; move the scrubber back one recorded state to show rewind restores the corresponding run. |

The final outcome and differences are computed from the path records; this script does not assume a particular label or result. If WebGL is unavailable, SVG fallback preserves selection, decisions, consequences, result, comparison, Why, and rewind, but it cannot demonstrate camera travel or moving 3D geometry.
