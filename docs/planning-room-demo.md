# Planning Room demo — two minutes

This route uses the existing College tech fest scenario and real rules. It assumes a fresh or reset Tech Fest run and uses **Secure a replacement sponsor** for each of its three decision turns. That sequence is verified to complete with three stars and two improved measures per turn, and it triggers the real supplier-risk event after the first sponsor action. A Foresight preview and one rewind consume their normal per-run charges; they do not change simulation values. Rewind once and repeat the sponsor choice before continuing.

| Time | Demonstration |
|---|---|
| 0:00–0:12 | Enter the Planning Room. Point out campaign stars, the persistent scenario table and Planner XP. Skip the boot line with Enter if it is still playing. |
| 0:12–0:27 | Open the room destination menu. Choose Campaign board, Drafting desk, then Medal shelf. The view glides to each landmark; the HTML menu remains the accessible navigation control. |
| 0:27–0:42 | Select College tech fest, begin, and use Foresight to read directions only. Explain that it does not commit a choice or reveal exact future values. |
| 0:42–1:02 | Choose Secure a replacement sponsor. Show the actual budget, days, morale and readiness changes, the 2-measure Chain, seeded paper burst and supplier-risk stinger. The stinger appears only because the real threshold fired. |
| 1:02–1:15 | Use Rewind. The prior recorded snapshot returns exactly; the charge and rewind log update. Choose the sponsor option again. |
| 1:15–1:37 | Complete turns two and three with the sponsor option. Continue through the real result. This verified sequence meets all three Tech Fest star criteria. |
| 1:37–1:48 | Read the result score, rank, stars, debrief, and Planner XP. A personal-best label or new achievement appears only if the saved record actually qualifies; this is profile-dependent. |
| 1:48–2:00 | Compare or inspect the recorded branch as available, return to the room, then select Drafting desk to open Scenario Studio. The Studio is available without changing built-in campaign configuration. |

For a visible “Both Ways” achievement, finish a genuine alternate branch for the same built-in scenario. For “No Regrets”, use a separate run without rewind; the demo above deliberately rewinds, so it does not qualify. A new-personal-best message depends on the local saved score and is not guaranteed on an existing profile.
