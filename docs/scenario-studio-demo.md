# Scenario Studio demo · 90 seconds

## 0:00–0:15 — Open Studio and create an edited copy

From the campaign picker, open **Edit built-in values → College tech fest → Edit values**. Point out that the Studio ID is separate and the original campaign entry remains intact. In **Measures**, change the starting budget value (the current Tech Fest Resources measure) and show the SVG preview's gauge and initial/final engine values update.

## 0:15–0:32 — Check balance

Move to **Outcomes**. Show the path count, best/median/worst scores, observed outcome labels, and reachability rows. Mention that these figures come from enumerating the engine's actual option sequences. Save the variant as playable only when the report has no hard errors.

## 0:32–0:48 — Play the variant

Return to **My situations**, locate the `Edited` item and use **Play**. The game launches the same simulation engine with the edited clone. Select a decision and inspect the resulting metric and event history; campaign stars and built-in best scores are not awarded to the variant.

## 0:48–1:00 — Return to the Studio

Use the top-bar **Studio** control when available, then **My situations**. The saved variant remains separate and can be edited, duplicated, exported, or removed. A removal can be restored with the six-second **Undo** action.

## 1:00–1:25 — Create a scenario from the template

Choose **Create a situation**. The default supplies four roles, three shared options, drift, events, outcome thresholds, score weights, mission/stretch criteria, and a sample path. Change the title and optionally adjust a measure or effect. The preview runs that path through the real engine.

## 1:25–1:30 — Validate and play

Open **Outcomes**, inspect the balance report, and choose **Save playable situation** when there are no hard errors. From the shelf, select **Play**. This short demo does not require a deliberately broken case, a specific rank, or campaign progression.
